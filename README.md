# us-realestate-val-ai

Enterprise AI Automated Valuation Model (AVM) and predictive investment risk analytics engine for U.S. residential real estate markets.

---

## 📈 Key Performance Metrics

The trained XGBoost valuation model evaluated on the synthetic U.S. residential housing dataset achieved the following performance benchmarks:

| Metric | Score / Value | Description |
| :--- | :--- | :--- |
| **$R^2$ Score** | **`0.9720`** | Proportion of variance explained by the model |
| **MAPE** | **`2.88%`** | Mean Absolute Percentage Error |
| **MAE** | **`$24,279.17`** | Mean Absolute Error in USD |
| **RMSE** | **`$30,908.70`** | Root Mean Squared Error in USD |
